# app de convertion entre XML et JSON

Ce projet est une application de convertion entre XML et JSON .
application JavaFX de conversion XML/JSON implémentant deux méthodes distinctes : une méthode professionnelle utilisant l'API Jackson avec Woodstox pour le parsing XML avancé, et une méthode pédagogique manuelle autonome sans dépendances externes.
